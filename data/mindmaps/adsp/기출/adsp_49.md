### 1번
* **문제:** 데이터베이스 아키텍처에서 데이터웨어하우스(DW)와 데이터 마트(DM)에 대한 설명으로 가장 적절한 것은?
* **보기:**
  1. 데이터 마트는 전사적 차원의 모든 원천 데이터를 통합 관리하는 대규모 중앙 저장소이다.
  2. 데이터웨어하우스는 특정 부서나 특정 분석 목적만을 위해 소규모로 구축된 하위 데이터베이스이다.
  3. 데이터 마트는 데이터웨어하우스로부터 특정 부서(마케팅, 영업 등)나 특정 분석 주제 영역에 초점을 맞추어 구축된 맞춤형 저장소이다.
  4. 데이터웨어하우스와 데이터 마트는 서로 상호작용할 수 없으며 동일한 시스템 내에 공존하는 것이 기술적으로 불가능하다.
* **정답:** **③**
* **해설:** 
  * **데이터웨어하우스(DW, Data Warehouse):** 기업의 전사적(Enterprise-wide) 의사결정을 지원하기 위해 여러 운영 시스템으로부터 데이터를 추출, 정제, 통합하여 축적한 대규모 중앙 저장소입니다.
  * **데이터 마트(DM, Data Mart):** 전사적 DW의 전체 데이터 중 특정 부서(예: 마케팅팀, 재무팀)나 특정 분석 주제 영역에 특화하여 데이터를 가공·요약한 소규모 맞춤형 데이터 저장소입니다.
  * 따라서 DW로부터 특정 분석 목적에 맞춰 구축된 저장소가 데이터 마트라는 설명인 ③번이 옳습니다.

### 2번
* **문제:** 노나카 이쿠지로의 지식창조 메커니즘인 SECI 모델에서, 개인이 오랜 업무 경험과 학습을 통해 내면에 체화하고 있는 '암묵지(Tacit Knowledge)'를 언어, 기호, 도표, 문서 등의 '형식지(Explicit Knowledge)'로 외부화하여 공유하는 지식 변환 단계는?
* **보기:**
  1. 표출화 (Externalization)
  2. 공통화 (Socialization)
  3. 연결화 (Combination)
  4. 내면화 (Internalization)
* **정답:** **①**
* **해설:** SECI 모델의 4대 지식 변환 나선 과정:
  * **표출화 (Externalization):** 암묵지 ➔ 형식지 (개인의 노하우나 직관적 경험을 문서, 매뉴얼, 설계도 등으로 명문화)
  * **공통화 (Socialization):** 암묵지 ➔ 암묵지 (견습, 대화, 공동 작업을 통해 경험과 노하우를 직접 전수)
  * **연결화 (Combination):** 형식지 ➔ 형식지 (기존 문서와 데이터들을 조합·편집·분류하여 새로운 체계 구축)
  * **내면화 (Internalization):** 형식지 ➔ 암묵지 (문서화된 지식을 개인이 학습하고 실천하여 자신의 노하우로 체화)

### 3번
* **문제:** 데이터로부터 가치를 창출하는 과정을 계층화한 DIKW(Data, Information, Knowledge, Wisdom) 피라미드에 관한 설명으로 가장 적절하지 **않은** 것은?
* **보기:**
  1. 가공되지 않은 순수 사실인 데이터를 수집·가공하면 중간 과정 없이 곧바로 지식(Knowledge) 단계로 직접 도약한다.
  2. 데이터(Data)는 객관적 사실(Fact)을 나타내며, 의미 부여가 되지 않은 순수한 관측값이다.
  3. 정보(Information)는 데이터에 의미와 맥락(Context)을 부여하여 패턴을 파악한 가공된 결과물이다.
  4. 지혜(Wisdom)는 축적된 지식에 통찰력과 경험이 결합되어 미래를 예측하고 창의적 아이디어를 도출하는 최상위 단계이다.
* **정답:** **①**
* **해설:** 
  * DIKW 피라미드는 **데이터(Data) ➔ 정보(Information) ➔ 지식(Knowledge) ➔ 지혜(Wisdom)**의 4단계 순차적 계층을 거칩니다.
  * 데이터를 가공하여 맥락을 부여한 1차 산출물은 **정보(Information)**이며, 정보들이 결합되고 일반화되어 규칙과 원리가 도출되어야 **지식(Knowledge)**이 됩니다. 중간의 정보(Information) 단계를 건너뛰고 곧바로 지식이 된다는 설명은 잘못되었습니다.

### 5번
* **문제:** 현대 정보 시스템 환경에서 데이터베이스(Database)가 갖는 고유한 특성 중, '정보 관리(Information Management)' 측면에서 데이터의 최신성과 동적인 상태 유지를 설명하는 특성으로 가장 적절한 것은?
* **보기:**
  1. 실시간 접근성 (Real-time Accessibility)
  2. 내용에 의한 참조 (Content Reference)
  3. 동시 공용 (Concurrent Sharing)
  4. 계속적인 변화 (Continuous Evolution)
* **정답:** **④**
* **해설:** 데이터베이스의 4대 운영 특성:
  * **계속적인 변화 (Continuous Evolution):** 데이터베이스는 현실 세계의 상태를 정확히 반영해야 하므로 삽입(Insert), 삭제(Delete), 갱신(Update)을 통해 항상 최신의 정확한 데이터를 동적으로 유지합니다.
  * 실시간 접근성: 질의에 대해 수 초 이내의 즉각적인 응답을 제공함
  * 동시 공용: 다수의 사용자가 동시에 동일한 데이터를 공유함
  * 내용에 의한 참조: 물리적 주소가 아닌 데이터의 값(내용)에 따라 검색됨

### 6번
* **문제:** 데이터베이스(DB)와 데이터베이스 관리 시스템(DBMS)의 구조적 특성에 대한 설명으로 가장 적절하지 **않은** 것은?
* **보기:**
  1. DBMS는 응용 프로그램과 물리적 데이터 파일 사이에서 데이터의 독립성과 무결성을 보장하는 시스템 소프트웨어이다.
  2. 관계형 데이터베이스(RDBMS)는 정규화 과정을 통해 데이터의 중복을 통제하고 무결성을 유지한다.
  3. 현대 빅데이터 환경에서는 그래프 DB, 문서 지향 DB, Key-Value DB 등 비관계형 NoSQL 데이터베이스도 널리 활용된다.
  4. 모든 데이터베이스는 물리적 저장 효율성을 위해 오직 고정된 2차원 관계형 행렬 테이블 구조로만 데이터가 저장된다.
* **정답:** **④**
* **해설:** 관계형 데이터베이스(RDBMS)는 2차원 테이블 구조를 사용하지만, 데이터베이스의 구조가 오직 2차원 테이블 형태로만 국한되는 것은 아닙니다. NoSQL, 객체 지향 DB, 계층형 DB, 그래프 DB 등 데이터의 특성과 목적에 따라 다양한 다차원 구조로 데이터가 저장·관리됩니다.

### 7번
* **문제:** 기업 정보 시스템의 데이터 처리 방식인 OLTP(Online Transaction Processing)와 OLAP(Online Analytical Processing)에 대한 설명으로 옳은 것은?
* **보기:**
  1. OLTP는 주로 경영진의 전략적 의사결정을 지원하기 위해 수년간 축적된 대용량 이력 데이터를 다차원으로 분석하는 시스템이다.
  2. OLAP는 데이터웨어하우스나 데이터 마트에 축적된 방대한 다차원 데이터를 빠르게 집계·조회하여 분석적 통찰을 얻는 시스템이다.
  3. OLAP는 계좌 이체, 주문 결제 등 실시간 업무 트랜잭션의 ACID 무결성 보장을 최우선 목표로 설계된다.
  4. OLTP 시스템에서는 복잡한 집계 쿼리와 통계 분석이 실시간 거래 트랜잭션보다 우선적으로 처리된다.
* **정답:** **②**
* **해설:** 
  * **OLTP (Online Transaction Processing):** 일상적인 비즈니스 거래(주문, 결제, 입출금 등)를 실시간으로 처리하며, 빠른 응답 속도와 트랜잭션 무결성(ACID) 유지가 핵심 목적입니다.
  * **OLAP (Online Analytical Processing):** 데이터웨어하우스(DW)에 저장된 대용량 이력 데이터를 다차원적 관점(Roll-up, Drill-down, Slicing, Dicing)에서 분석하여 의사결정을 지원하는 분석 지향 시스템입니다.

### 8번
* **문제:** 다음 보기는 빅데이터 시대의 3대 위기 요인(사생활 침해, 책임 원칙 훼손, 데이터 오용)과 이에 대응하기 위한 통제 기제에 대한 설명이다. 옳은 항목만을 모두 고른 것은?
> [보기]  
> ㄱ. 빅데이터 환경에서는 개인정보의 비식별화 및 동의제가 완벽히 작동하므로 사후적 통제는 전혀 필요하지 않다.  
> ㄴ. 빅데이터의 활용이 예측 알고리즘 기반으로 발전함에 따라, 아직 발생하지 않은 잠재적 행위에 대해 사전 처벌하는 책임 원칙 훼손 문제가 발생할 수 있다.  
> ㄷ. 데이터 수집 시 사전 동의(Opt-in) 제도를 강화하는 것이 빅데이터 활용에 따른 사생활 침해를 완벽히 통제하는 현대적 패러다임이다.  
> ㄹ. 데이터 분석 모델의 편향이나 잘못된 통계적 해석으로 인해 부당한 피해가 발생하는 '데이터 오용'에 대해서는 규제나 감사 기제가 불필요하다.  
> ㅁ. 알고리즘의 복잡성으로 인한 피해를 통제하고 설명 책임을 부여하기 위해 '알고리즈미스트(Algorithmist)'와 같은 전문 감시 기제의 필요성이 대두되었다.
* **보기:**
  1. ㄱ, ㄷ
  2. ㄴ, ㅁ
  3. ㄴ, ㄷ, ㄹ
  4. ㄱ, ㄴ, ㅁ
* **정답:** **② (ㄴ, ㅁ)**
* **해설:** 
  * ㄱ: 데이터 결합을 통해 재식별화될 위험이 상존하므로 강력한 사후 통제가 필수적입니다. (오답)
  * ㄷ: 빅데이터 환경에서는 어디서 데이터가 어떻게 쓰일지 사전에 알기 어려우므로, '사전 동의제' 중심에서 '개인정보 사용자의 사후 책임 원칙 강화'로 패러다임이 전환되었습니다. (오답)
  * ㄹ: 데이터 오용을 방지하기 위해 알고리즘의 객관성 감사 및 설명가능성(XAI) 보장이 요구됩니다. (오답)
  * ㄴ과 ㅁ은 책임 원칙 훼손의 위험과 알고리즈미스트의 역할에 대해 바르게 설명하고 있습니다.

### 9번
* **문제:** 컴퓨터 및 디지털 정보 시스템에서 데이터를 표현하고 저장하는 용량 단위의 크기를 작은 것부터 큰 순서로 바르게 나열한 것은?
* **보기:**
  1. Byte ➔ KB ➔ GB ➔ MB ➔ TB ➔ PB
  2. Byte ➔ KB ➔ MB ➔ GB ➔ TB ➔ PB
  3. Byte ➔ MB ➔ KB ➔ TB ➔ GB ➔ PB
  4. Bit ➔ Byte ➔ TB ➔ GB ➔ MB ➔ PB
* **정답:** **②**
* **해설:** 디지털 데이터 용량 단위의 표준 계층 순서:
$$\text{Bit} \to \text{Byte} (8\text{ bits}) \to \text{KB} (2^{10}) \to \text{MB} (2^{20}) \to \text{GB} (2^{30}) \to \text{TB} (2^{40}) \to \text{PB} (2^{50}) \to \text{EB} (2^{60}) \to \text{ZB} (2^{70}) \to \text{YB} (2^{80})$$
따라서 Byte ➔ KB ➔ MB ➔ GB ➔ TB ➔ PB 순서인 ②번이 올바릅니다.

  1. 감성 분석 (Sentiment Analysis)
  2. 소셜 네트워크 분석 (Social Network Analysis)
  3. 장바구니 분석 (Market Basket Analysis)
  4. 유전 알고리즘 (Genetic Algorithm)
* **정답:** **④**
* **해설:** 
  * **유전 알고리즘(Genetic Algorithm):** 생물의 진화 과정(염색체 교차, 돌연변이, 적자생존에 의한 도태 등)을 모델링하여 복잡한 최적화 문제나 최적 조합을 탐색하는 인공지능 최적화 기법입니다. (사례: 물류 운송 경로 최적화, 통신망 설계)
  * 감성 분석은 텍스트의 감정 극성을 분류하는 기법, SNA는 개체 간 네트워크 구조 분석, 장바구니 분석은 동시 구매 품목 간의 연관규칙을 탐색하는 기법입니다.

## 제2과목: 데이터 분석 기획 (11번 ~ 20번)

### 11번
* **문제:** 분석 과제 발굴을 위한 4사분면 매트릭스(분석 대상 What x 분석 방법 How)의 4가지 유형에 대한 설명으로 가장 적절하지 **않은** 것은?
* **보기:**
  1. 최적화 (Optimization): 분석 대상(What)과 분석 방법(How)을 모두 명확히 알고 있을 때 수행하는 과제 유형이다.
  2. 솔루션 (Solution): 분석 대상(What)은 명확히 알고 있으나 이를 해결하기 위한 구체적인 분석 방법(How)을 모를 때 수행하는 과제 유형이다.
  3. 통찰 (Insight): 분석 대상(What)도 모르고 분석 방법(How)도 전혀 모르는 상태에서 새로운 기회를 탐색하는 과제 유형이다.
  4. 발견 (Discovery): 분석 대상(What)과 분석 방법(How)을 모두 모르는 상태에서 데이터 탐색을 통해 과제를 새롭게 도출하는 유형이다.
* **정답:** **③**
* **해설:** 분석 과제 발굴의 4대 사분면 매트릭스:
  * **최적화 (Optimization):** 대상 앎(Known) + 방법 앎(Known)
  * **솔루션 (Solution):** 대상 앎(Known) + 방법 모름(Un-known)
  * **통찰 (Insight):** 대상 모름(Un-known) + 방법 앎(Known) ➔ 새로운 통찰과 관점을 도출
  * **발견 (Discovery):** 대상 모름(Un-known) + 방법 모름(Un-known) ➔ 데이터로부터 발견
  * ③ 대상과 방법을 모두 모르는 것은 '발견(Discovery)'이며, '통찰(Insight)'은 대상을 모를 때 기존의 분석 방법을 적용하여 통찰을 얻는 것입니다.

### 12번
* **문제:** 빅데이터 분석 방법론의 라이프사이클 중 '평가 및 전개(배포)' 단계에서 수행하는 활동에 대한 설명으로 가장 적절하지 **않은** 것은?
* **보기:**
  1. 개발된 모델의 비즈니스 목표 달성 여부와 실무 적용성을 최종 검증하고 승인한다.
  2. 모델 배포 후 안정적인 운영을 위한 모니터링 계획과 성능 저하 시의 재학습 관리 방안은 이 단계에서 일체 배제한다.
  3. 모델의 실제 서비스 배포를 위한 운영 환경 이관 및 시스템 연동 작업을 수행한다.
  4. 프로젝트 종료 후 최종 산출물 정리와 사후 유지보수 계획을 수립한다.
* **정답:** **②**
* **해설:** 평가 및 전개(배포) 단계에서는 개발된 분석 모델을 실무 시스템에 성공적으로 배포할 뿐만 아니라, 배포 이후 데이터 분포 변화(Data Drift)나 성능 저하에 대비한 **운영 모니터링 계획, 주기적 재학습(Retraining) 전략, 장애 대응 프로세스를 반드시 포함**하여 수립해야 합니다. 이를 배제한다는 ②번은 잘못되었습니다.

### 13번
* **문제:** 분석 프로젝트 수행 방법론 중, 초기 요구사항이 불명확한 환경에서 핵심 프로세스를 반복적으로 수행하면서 위험을 조기에 식별하고 프로젝트의 완성도를 점진적으로 발전시켜 나가는 모델은?
* **보기:**
  1. 폭포수 모델 (Waterfall Model)
  2. 프로토타입 모델 (Prototyping Model)
  3. 나선형 모델 (Spiral Model)
  4. 계층적 KDD 모델 (Hierarchical KDD Model)
* **정답:** **③**
* **해설:** 
  * **나선형 모델 (Spiral Model):** 계획 수립 ➔ 위험 분석 ➔ 개발 및 검증 ➔ 고객 평가의 사이클을 나선형으로 반복(Iteration)하며 점진적으로 시스템을 완성해 나가는 모델로, 대규모 프로젝트에서 **위험 관리(Risk Management)**를 체계화하는 데 최적화되어 있습니다.
  * 폭포수 모델은 순차적 일방향 모델, 프로토타입 모델은 조기 시제품 제작 및 피드백 모델입니다.

### 14번
* **문제:** 데이터 분석 프로젝트의 품질 관리 및 통계적 평가에서 사용되는 '정확도(Accuracy)'와 '정밀도(Precision)'의 개념을 과녁판 비유로 설명할 때, 가장 올바른 설명은?
* **보기:**
  1. 정밀도(Precision)는 반복적으로 측정했을 때 관측값들이 얼마나 일관되게 한곳에 모여 있는지를 나타내는 '안정성(재현성)' 측면의 척도이다.
  2. 정확도(Accuracy)는 관측값들이 서로 얼마나 밀집해 있는지만을 측정하며, 목표 과녁 중심과의 거리는 전혀 고려하지 않는다.
  3. 관측값들이 목표 과녁 중심에서는 멀리 벗어나 있더라도 조밀하게 한곳에 모여 있다면 정확도가 높은 상태이다.
  4. 정밀도는 데이터 분석 모형의 평균적인 편향(Bias)만을 나타내며, 측정의 분산(Variance)과는 아무런 관련이 없다.
* **정답:** **①**
* **해설:** 
  * **정확도 (Accuracy):** 측정값들의 평균(중심)이 참값(목표 과녁 중심)에 얼마나 가까운가를 나타내는 척도 (편향 Bias가 낮음).
  * **정밀도 (Precision):** 반복 측정 시 측정값들 간에 서로 얼마나 밀접하게 모여 있는가를 나타내는 척도로, **반복 측정의 안정성 및 일관성(분산 Variance가 낮음)**을 의미합니다.
  * 과녁 중심에서 벗어나 있더라도 좁게 뭉쳐 있는 것은 정밀도(Precision)는 높으나 정확도(Accuracy)는 낮은 상태입니다. 따라서 ①번이 정확한 설명입니다.

### 15번
* **문제:** 데이터 분석 과제 발굴 방식 중 '상향식 접근법(Bottom-Up Approach)'에 대한 설명으로 가장 적절한 것은?
* **보기:**
  1. 경영진이나 고객의 명확한 요구사항과 사전에 정의된 문제로부터 출발하여 연역적으로 가설을 검증하는 방식이다.
  2. 해결해야 할 문제가 구체적으로 정의되지 않은 상태에서, 현재 보유하고 있는 원천 데이터 자체를 탐색(EDA)하여 숨겨진 패턴과 새로운 통찰을 발굴하는 귀납적 방식이다.
  3. 분석 과제의 수행 일정이 엄격히 정해져 있어 순차적인 폭포수 개발 절차만을 준수하는 방식이다.
  4. 사전에 전사적인 중장기 로드맵을 완벽하게 확정해 놓고 단 1회의 수정 없이 일방향으로만 추진하는 방식이다.
* **정답:** **②**
* **해설:** 
  * **상향식 접근법(Bottom-Up Approach):** 데이터 자체의 관찰과 비지도 학습, 탐색적 데이터 분석(EDA)을 통해 생각지 못했던 새로운 비즈니스 통찰과 분석 과제를 상향식으로 발굴하는 접근법입니다 (데이터 기반 ➔ 문제 도출).
  * ①은 하향식(Top-Down) 접근법에 대한 설명입니다.

### 16번
* **문제:** 분석 과제 발굴 방식 중 '하향식 접근법(Top-Down Approach)'의 전형적인 특징으로 가장 적절한 것은?
* **보기:**
  1. 가설 설정 없이 원천 데이터로부터 군집분석이나 연관분석을 우선 수행하여 문제를 찾는다.
  2. 현장 실무자가 비공식적으로 수집한 비정형 로그 데이터의 자유로운 탐색을 우선시한다.
  3. 해결해야 할 비즈니스 문제와 달성 목표가 명확히 정의된 상태에서, 이를 해결하기 위한 분석 가설을 수립하고 단계별로 데이터를 분석·검증해 나간다.
  4. 초기 문제 정의를 일체 수행하지 않고 머신러닝 모델의 파라미터 튜닝부터 먼저 착수한다.
* **정답:** **③**
* **해설:** **하향식 접근법(Top-Down Approach)**은 기업의 전략적 목표나 당면한 비즈니스 이슈가 명확할 때, '문제 탐색 ➔ 문제 정의 ➔ 해결방안 탐색 ➔ 타당성 검토'의 4단계를 거쳐 문제를 체계적으로 구체화하고 가설을 검증하는 전통적인 하향식 과제 도출 방식입니다.

### 17번
* **문제:** 현대 기업 환경에서 효과적인 데이터 분석 과제 발굴 및 방법론의 수립 원칙으로 가장 적절하지 **않은** 것은?
* **보기:**
  1. 실제 기업 환경에서는 하향식 접근법과 상향식 접근법이 상호 배타적인 것이 아니라 유기적으로 결합되어 보완적으로 수행된다.
  2. 빅데이터 분석 방법론을 적용할 때는 과거의 전통적인 분석 기법이나 현업의 경험적 가설을 전면 배격하고 오직 머신러닝 알고리즘에만 의존해야 한다.
  3. 하향식 접근법으로 거시적인 문제의 틀을 잡고, 상향식 접근법을 통해 구체적인 세부 인사이트와 실행 과제를 구체화할 수 있다.
  4. 비즈니스 환경의 불확실성에 대응하기 위해 디자인 씽킹(Design Thinking)의 발산과 수렴 과정을 융합하여 분석 과제를 발굴한다.
* **정답:** **②**
* **해설:** 현대 데이터 분석 방법론은 전통적인 통계 가설 검정과 머신러닝 데이터 마이닝을 융합하며, 현업 도메인의 경험적 지식과 데이터 기반 상향식 통찰을 상호 보완하여 통합합니다. 전통적 분석을 전면 배격하고 인공지능에만 의존해야 한다는 설명은 잘못되었습니다.

### 18번
* **문제:** 기업 내 데이터 분석 인프라 및 아키텍처 수립 시, 조직의 전사적 의사결정을 지원하기 위해 구축하는 '정보 시스템(Information System)'의 핵심 목적에 대한 설명으로 옳은 것은?
* **보기:**
  1. 조직의 내·외부 데이터를 체계적으로 수집, 저장, 가공, 분석하여 의사결정권자에게 적시에 유용한 정보를 제공함으로써 비즈니스 가치를 창출한다.
  2. 단순 하드웨어 서버 장비의 물리적 전원 공급만을 관리하는 시설 관리 시스템이다.
  3. 모든 분석 알고리즘의 소스코드를 외부 대중에게 무조건 실시간 공개하는 오픈소스 배포 시스템이다.
  4. 기업 내부의 모든 전산 데이터를 1개월 주기로 영구 삭제하여 저장 공간을 초기화하는 정리 도구이다.
* **정답:** **①**
* **해설:** 정보 시스템(IS, Information System)은 조직의 경영 목표를 달성하기 위해 데이터를 수집, 처리, 저장, 분배하여 효율적인 운영과 데이터 기반의 합리적인 의사결정을 지원하는 체계적인 시스템입니다.

### 19번
* **문제:** 데이터 분석 조직의 구조 유형 중, 전사 차원의 분석 업무를 총괄하는 별도의 독립적인 '분석 전담 부서(CoE: Center of Excellence)'를 조직하고, 해당 부서에서 전사 분석 과제의 기획, 인력 배분, 인프라 관리를 집중적으로 수행하는 조직 구조는?
* **보기:**
  1. 집중형 조직 구조 (Centralized Structure)
  2. 기능형 조직 구조 (Functional Structure)
  3. 분산형 조직 구조 (Decentralized Structure)
  4. 임시 태스크포스 구조 (Ad-hoc TF Structure)
* **정답:** **①**
* **해설:** 분석 조직 구조의 3대 유형:
  * **집중형 (Centralized):** 별도의 전사 분석 전담 조직을 구성하여 전사 과제를 총괄 기획·조정하며 분석 역량을 집중시킴. (우선순위 조율 용이, 현업과의 이질감 발생 가능)
  * **기능형 (Functional):** 별도 전담 조직 없이 각 현업 부서(마케팅, 인사 등) 내부에서 자체적으로 분석을 수행함. (전사적 협업 부족, 중복 분석 위험)
  * **분산형 (Decentralized):** 분석 전담 인력을 각 현업 부서에 직접 배치하여 현업 밀착형 분석을 수행하고 본사 CoE와 유기적 협력 관계 유지.

### 20번
* **문제:** 데이터 분석 환경을 제공하는 '분석 플랫폼(Analytics Platform)'의 구성 요소를 좁은 의미(협의의 플랫폼)와 넓은 의미(광의의 플랫폼)로 구분할 때, 다음 중 '협의의 분석 플랫폼'을 구성하는 핵심 도구 및 소프트웨어 계층에 해당하지 **않는** 것은?
* **보기:**
  1. 분석 엔진 및 통계·머신러닝 분석 라이브러리 도구
  2. 분석용 정형·비정형 데이터 저장소 (Data Repository)
  3. 시각화 대시보드 및 분석 개발 환경 도구 (IDE/UI)
  4. 데이터 센터 건물, 항온항습 설비 및 전력 공급 인프라
* **정답:** **④**
* **해설:** 
  * **협의의 분석 플랫폼:** 데이터 수집·저장 도구, 분석 엔진(R, Python, Spark 등), 분석 라이브러리, 시각화 도구, 분석 인터페이스 등 분석을 직접 수행하기 위한 핵심 소프트웨어 및 솔루션 환경을 의미합니다.
  * ④ 데이터 센터 건물, 물리적 서버실 전력 설비 등은 광의의 물리적 인프라 영역이며, 협의의 분석 플랫폼 구성 요소로 보기 어렵습니다.

### 22번
* **문제:** 통계적 가설검정(Hypothesis Testing)의 기본 원리와 용어에 대한 설명으로 가장 적절하지 **않은** 것은?
* **보기:**
  1. 제1종 오류(Type I Error)는 실제 귀무가설이 참인데도 불구하고 잘못하여 귀무가설을 기각하는 오류이다.
  2. 유의수준(Significance Level, $\alpha$)은 연구자가 허용할 수 있는 제1종 오류의 최대 허용 한계이다.
  3. 유의확률($p$-value)은 귀무가설이 참이라는 가정하에 현재 표본에서 관측된 것보다 더 극단적인 통계량이 관측될 확률이다.
  4. 계산된 $p$-value가 설정한 유의수준($\alpha$)보다 클수록 귀무가설을 기각하고 대립가설을 채택할 강력한 통계적 근거가 된다.
* **정답:** **④**
* **해설:** 
  * 통계적 의사결정 규칙: **$p\text{-value} < \alpha$ (유의수준) 일 때 귀무가설($H_0$)을 기각**하고 대립가설($H_1$)을 채택합니다.
  * $p$-value가 유의수준보다 크다는 것은 현재의 결과가 우연히 발생했을 가능성이 높다는 의미이므로, 귀무가설을 기각하지 못합니다(채택). 따라서 클수록 기각한다는 ④번 설명은 정반대입니다.

### 23번
* **문제:** 확률 및 확률분포에 관한 설명으로 가장 적절한 것은?
* **보기:**
  1. 이산확률변수의 확률질량함수(PMF)에서 특정 값에 대한 확률은 $1$을 초과할 수 있다.
  2. 이산확률분포의 모든 가능한 사건들에 대한 확률의 총합은 항상 $0$이다.
  3. 연속확률변수의 확률밀도함수(PDF) $f(x)$에서 전체 면적의 적분값은 $1$이지만, 특정 지점에서의 함수 높이 $f(x)$ 자체는 $1$보다 큰 값을 가질 수 있다.
  4. 연속확률분포에서 어떤 정확한 특정 실수 한 점($X = c$)이 발생할 확률은 항상 $1$이다.
* **정답:** **③**
* **해설:** 
  * **연속확률변수:** 확률밀도함수(PDF)의 전체 구간 적분(면적)은 반드시 $1$이어야 합니다 ($\int_{-\infty}^{\infty} f(x) dx = 1$). 하지만 구간 폭이 매우 좁은 균등분포(예: $X \sim U(0, 0.5)$)의 경우, 면적이 1이 되기 위해 함수 높이 $f(x) = \frac{1}{0.5 - 0} = 2$로 **$1$을 초과**할 수 있습니다. 따라서 ③번은 매우 정확하고 중요한 성질입니다.
  * ① PMF의 각 확률은 $0 \le P(X=x) \le 1$입니다.
  * ② 모든 확률의 합은 $1$입니다.
  * ④ 연속형 분포에서 정확한 한 점의 확률은 수학적으로 $P(X=c) = 0$입니다.

### 24번
* **문제:** 단순 선형 회귀분석 모형의 성능을 평가하는 결정계수($R^2$)에 대한 설명으로 가장 적절하지 **않은** 것은?
* **보기:**
  1. 결정계수($R^2$)는 종속변수 $Y$의 전체 총변동(SST) 중에서 회귀모형(SSR)에 의해 설명되는 변동의 비율을 의미한다.
  2. 설명변수가 포함된 일반적인 선형 회귀모형의 결정계수($R^2$)는 아무리 적합도가 낮더라도 통계적으로 무조건 $+1$ 이상의 값을 갖는다.
  3. 설명변수 없이 오직 종속변수의 표본평균($\bar{Y}$)만으로 모든 관측값을 예측하는 단순 기준 모형의 경우 결정계수는 $0$이 된다.
  4. 단순 선형 회귀모형에서 결정계수($R^2$)는 두 변수 간의 피어슨 상관계수($r$)의 제곱($r^2$)과 일치한다.
* **정답:** **②**
* **해설:** 
  * 결정계수($R^2 = \frac{\text{SSR}}{\text{SST}} = 1 - \frac{\text{SSE}}{\text{SST}}$)는 일반적으로 **$0$에서 $1$ 사이**의 값을 갖습니다 ($0 \le R^2 \le 1$). 무조건 1 이상의 값을 갖는다는 ②번은 명백한 오류입니다.
  * 평균으로만 예측할 때 $\text{SSE} = \text{SST}$가 되어 $R^2 = 0$이 되며, 모형이 완벽히 데이터를 설명할 때 $\text{SSE} = 0$이 되어 $R^2 = 1$이 됩니다.

* **보기:**
  1. 단순무작위추출법: 모집단의 모든 개체에 고유 번호를 부여하고 동일한 확률로 무작위 표본을 추출한다.

  3. 집락추출법 (군집추출법): 모집단을 서로 동질적인 여러 개의 하위 층으로 나눈 뒤, 각 층 내부에서 표본을 추출하며 집락 내부는 극도로 동질적이어야 한다.

  * **집락추출법 (Cluster Sampling):** 군집 간(Between)은 동질적이고, 군집 내(Within)는 이질적이어야 함 (모집단의 축소판 형태).
  * ③번은 집락추출법에 층화추출법의 특성을 잘못 섞어 설명하고 있으므로 오답입니다.

### 27번
* **문제:** 이산확률변수 $X$가 가질 수 있는 값 $x_i$와 이에 대응하는 확률 $P(X=x_i)$의 분포가 다음과 같이 주어졌을 때, 확률변수 $X$의 기댓값 $E(X)$는 얼마인가?
> [확률분포표]  
> - $P(X = 1) = \frac{1}{6}$  
> - $P(X = 2) = \frac{1}{2} = \frac{3}{6}$  
> - $P(X = 3) = \frac{1}{3} = \frac{2}{6}$
* **보기:**
  1. $1$
  2. $\frac{7}{6}$
  3. $2$
  4. $\frac{13}{6}$
* **정답:** **④**
* **해설:** 이산확률변수의 기댓값 공식 $E(X) = \sum x_i \cdot P(X=x_i)$ 를 적용하여 계산합니다.
$$E(X) = 1 \times \frac{1}{6} + 2 \times \frac{1}{2} + 3 \times \frac{1}{3} = \frac{1}{6} + 1 + 1 = \frac{1}{6} + 2 = \frac{1}{6} + \frac{12}{6} = \frac{13}{6} \approx 2.167$$
따라서 올바른 기댓값은 ④번 $\frac{13}{6}$ 입니다.

### 28번
* **문제:** 확률변수 $X$에 대하여 양수 $a$와 상수 $b$를 적용하여 새로운 확률변수 $Z = aX + b$로 선형 변환(Linear Transformation)을 수행하였다. 이때 원래 변수 $X$의 통계량과 비교하여 그 수치가 변하지 않고 그대로 유지되는(불변인) 통계량은?
* **보기:**
  1. 왜도 (Skewness)
  2. 표본평균 (Mean)
  3. 중앙값 (Median)
  4. 표준편차 (Standard Deviation)
* **정답:** **①**
* **해설:** 
  * 선형 변환 $Z = aX + b$ ($a > 0$) 적용 시:
    * 평균: $E(Z) = aE(X) + b$ (변화함)
    * 중앙값: $\text{Median}(Z) = a\text{Median}(X) + b$ (변화함)
    * 분산: $\text{Var}(Z) = a^2 \text{Var}(X)$ ➔ 표준편차: $\text{SD}(Z) = a\text{SD}(X)$ (변화함)
    * **왜도(Skewness):** 왜도는 $E\left[\left(\frac{X - \mu}{\sigma}\right)^3\right]$ 으로 정의되는 3차 표준화 모멘트입니다. 분자의 편차 세제곱에서 $a^3$이 나오고 분모의 표준편차 세제곱에서도 $a^3$이 나와 서로 약분되므로, **양수 $a$에 의한 선형 변환 시 왜도는 변하지 않고 불변**입니다.

### 29번
* **문제:** 두 변수 $X$와 $Y$ 간의 피어슨 상관계수가 $r(X, Y) = 0.2$로 주어져 있다. 변수 $X$에 대하여 새로운 변수 $U = -3X + 5$를 정의하고, 변수 $V = 2Y - 7$을 정의했을 때, 두 새로운 변수 $U$와 $V$ 간의 피어슨 상관계수 $r(U, V)$의 값은?
* **보기:**
  1. $-0.2$
  2. $0.2$
  3. $-0.6$
  4. $0.0$
* **정답:** **①**
* **해설:** 
  * 피어슨 상관계수의 선형 변환 공식: $U = aX + b$, $V = cY + d$ 일 때,
$$r(U, V) = \frac{a \cdot c}{|a| \cdot |c|} r(X, Y)$$
  * 여기서 $X$의 계수 $a = -3 < 0$ (음수)이고, $Y$의 계수 $c = 2 > 0$ (양수)입니다.
  * 따라서 상수 덧셈/뺄셈 및 양수 곱셈은 상관계수의 크기에 영향을 주지 않지만, 하나의 변수에 음수가 곱해졌으므로 선형 방향이 반대로 반전됩니다.
$$r(U, V) = \frac{(-3) \times 2}{|-3| \times |2|} \times 0.2 = \frac{-6}{6} \times 0.2 = -1 \times 0.2 = -0.2$$

### 31번
* **문제:** 시계열 데이터가 통계적 정상성(Stationarity)을 만족하기 위해 충족해야 하는 3대 기본 가정에 해당하지 **않는** 것은?
* **보기:**
  1. 시계열 데이터의 모든 시점 간 관측값들은 어떠한 상관성도 없이 서로 통계적 독립(Independent)이어야 한다.
  2. 시계열의 평균은 시간에 따라 변하지 않고 항상 일정해야 한다.
  3. 시계열의 분산은 시간에 의존하지 않고 항상 일정해야 한다.
  4. 두 시점 사이의 공분산(자기공분산)은 특정 시점의 위치가 아니라 오직 두 시점 간의 시차(Lag, $k$)에만 의존해야 한다.
* **정답:** **①**
* **해설:** 정상 시계열(Stationary Time Series)의 3대 조건:
  1. **평균의 일정성:** 시간에 무관하게 평균이 상수임
  2. **분산의 일정성:** 시간에 무관하게 분산이 유한하고 일정함
  3. **자기공분산의 시차 의존성:** $\text{Cov}(Y_t, Y_{t-k}) = \gamma_k$ 로 오직 시차 $k$에만 의존함

### 44번
* **문제:** 이진 분류 모형의 예측 결과를 나타낸 혼동 행렬(Confusion Matrix)이 다음과 같다. 이 모형의 '양성(Positive) 클래스'에 대한 $F_1\text{-Score}$ (정밀도와 재현율의 조화평균)는 얼마인가?
> [혼동 행렬]  
> - 실제 Positive 중 예측 Positive (TP): 3  
> - 실제 Positive 중 예측 Negative (FN): 5  
> - 실제 Negative 중 예측 Positive (FP): 8  
> - 실제 Negative 중 예측 Negative (TN): 24
* **보기:**
  1. $\frac{6}{19}$
  2. $\frac{3}{8}$
  3. $\frac{3}{11}$
  4. $\frac{19}{6}$
* **정답:** **①**
* **해설:** 
  1. **재현율 (Recall):** $\text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}} = \frac{3}{3 + 5} = \frac{3}{8}$
  2. **정밀도 (Precision):** $\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}} = \frac{3}{3 + 8} = \frac{3}{11}$
  3. **$F_1\text{-Score}$ (조화평균):**
$$F_1 = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} = 2 \times \frac{\frac{3}{11} \times \frac{3}{8}}{\frac{3}{11} + \frac{3}{8}} = 2 \times \frac{\frac{9}{88}}{\frac{24 + 33}{88}} = 2 \times \frac{9}{57} = \frac{18}{57} = \frac{6}{19} \approx 0.3158$$
따라서 올바른 $F_1\text{-Score}$는 ①번 $\frac{6}{19}$ 입니다.

### 48번
* **문제:** 2차원 좌표평면 상의 두 점 $A(x_1, y_1)$과 $B(x_2, y_2)$ 사이의 거리를 측정할 때, 격자형 도로망을 따라 이동하는 '맨해튼 거리(Manhattan Distance, $L_1$)'와 두 점 사이의 최단 직선거리인 '유클리드 거리(Euclidean Distance, $L_2$)'의 크기 관계에 대한 설명으로 옳은 것은?
* **보기:**
  1. 두 점이 동일한 좌표가 아닌 일반적인 경우, 맨해튼 거리는 항상 유클리드 거리보다 크거나 같다 ($L_1 \ge L_2$).
  2. 맨해튼 거리는 항상 유클리드 거리보다 작다 ($L_1 < L_2$).
  3. 맨해튼 거리와 유클리드 거리는 항상 모든 좌표에서 완벽히 일치한다.
  4. 맨해튼 거리는 음수 값을 가질 수 있지만 유클리드 거리는 양수만 가능하다.
* **정답:** **①**
* **해설:** 
  * 맨해튼 거리: $L_1 = |x_1 - x_2| + |y_1 - y_2|$
  * 유클리드 거리: $L_2 = \sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$
  * 직각삼각형의 삼각부등식에 의해 두 직각변의 길이 합($L_1$)은 빗변의 길이($L_2$)보다 항상 크거나 같습니다 ($L_1 \ge L_2$). 두 점의 $x$좌표나 $y$좌표가 같을 때만 $L_1 = L_2$가 성립합니다. 따라서 ①번이 정확합니다.

### 49번
* **문제:** 대형 마트의 100건 거래 영수증 데이터를 분석한 결과, '기저귀'가 포함된 거래가 51건, '맥주'가 포함된 거래가 50건, 그리고 '기저귀와 맥주'가 동시에 함께 장바구니에 담긴 거래가 34건이었다. 이때 연관규칙 $\text{기저귀} \rightarrow \text{맥주}$ 의 '신뢰도(Confidence)'는 약 얼마인가?
* **보기:**
  1. 0.34 (34%)
  2. 0.51 (51%)
  3. 0.67 (약 67%)
  4. 1.33 (133%)
* **정답:** **③**
* **해설:** 연관규칙 $A \to B$의 신뢰도(Confidence) 공식:
$$\text{Confidence}(A \to B) = \frac{n(A \cap B)}{n(A)}$$
  * 조건절 $A$(기저귀) 구매 건수: $n(A) = 51$건
  * 동시 구매 $A \cap B$(기저귀와 맥주) 건수: $n(A \cap B) = 34$건
$$\text{Confidence}(\text{기저귀} \to \text{맥주}) = \frac{34}{51} = \frac{2}{3} \approx 0.6667\;(66.7\%)$$
따라서 약 $0.67$ (67%)인 ③번이 정답입니다.

### 50번
* **문제:** 앞선 49번 문제의 100건 마트 영수증 데이터(전체 거래 건수 $N = 100$, 기저귀 51건, 맥주 50건, 기저귀와 맥주 동시 구매 34건)에서, 연관규칙 $\text{기저귀} \rightarrow \text{맥주}$ 의 '지지도(Support)'는 얼마인가?
* **보기:**
  1. 0.51 (51%)
  2. 0.50 (50%)
  3. 0.34 (34%)
  4. 0.67 (67%)
* **정답:** **③**
* **해설:** 연관규칙 $A \to B$의 지지도(Support) 공식:
$$\text{Support}(A \to B) = \frac{n(A \cap B)}{N}$$
  * 전체 거래 건수: $N = 100$건
  * 품목 $A$와 $B$가 동시에 포함된 거래 건수: $n(A \cap B) = 34$건
$$\text{Support} = \frac{34}{100} = 0.34\;(34\%)$$
지지도(Support)는 규칙의 방향에 무관하게 두 품목이 전체 거래 중 함께 발생할 결합 비율이므로 $0.34$ (34%)인 ③번이 정답입니다.
