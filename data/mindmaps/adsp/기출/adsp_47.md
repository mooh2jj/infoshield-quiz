# ADsP 제47회 기출문제 및 해설 풀이 (전체 50문항)

## 제1과목: 데이터 이해 (1번 ~ 10번)

### 1번
* **문제:** 다음 중 암묵지(Tacit Knowledge)와 형식지(Explicit Knowledge)의 상호작용을 나타내는 SECI 모델의 올바른 순환 과정은?
* **보기:**
  1. 공통화(Socialization) → 표출화(Externalization) → 연결화(Combination) → 내면화(Internalization)
  2. 표출화(Externalization) → 공통화(Socialization) → 내면화(Internalization) → 연결화(Combination)
  3. 연결화(Combination) → 표출화(Externalization) → 공통화(Socialization) → 내면화(Internalization)
  4. 내면화(Internalization) → 연결화(Combination) → 표출화(Externalization) → 공통화(Socialization)
* **정답:** **①**
* **해설:** 노나카 이쿠지로의 지식 변환 SECI 모델은 개인 간 경험 공유를 통한 **공통화(Socialization)** → 암묵지를 개념이나 문서로 명문화하는 **표출화(Externalization)** → 형식지들을 체계적으로 편집·결합하는 **연결화(Combination)** → 학습을 통해 개인의 암묵지로 체화하는 **내면화(Internalization)**의 선순환 나선 구조를 따릅니다.

### 2번
* **문제:** 다음 DIKW 피라미드 단계에 해당하는 사례 중, 나머지 셋과 다른 위계(단계)에 속하는 것은?
* **보기:**
  1. A 마트에서 연필은 100원, 공책은 200원에 판매한다.
  2. 어느 동호회에 가입한 남성은 30명, 여성은 10명이다.
  3. 오늘 서울의 최저 기온은 영상 5도, 최고 기온은 15도이다.
  4. 과거 구매 이력 분석 결과 이번 주말 마트 방문 고객이 우유를 구매할 확률은 30%로 예측된다.
* **정답:** **④**
* **해설:** 1, 2, 3번은 가공되지 않은 순수한 객관적 사실이나 수치를 기록한 **데이터(Data)** 단계입니다. 반면 4번은 데이터를 패턴화하고 상관관계를 해석하여 미래 행동을 예측할 수 있도록 가공된 **지식(Knowledge)** 또는 **정보(Information)** 단계에 해당하므로 유형이 다릅니다.

### 3번
* **문제:** 다음 보기의 내용은 데이터베이스의 다양한 특성 중 어떤 측면에 대한 설명인가?
> [보기]  
> 대량의 정보를 정보처리기기가 읽고 쓸 수 있는 기계 가독성(Machine Readability), 필요한 정보를 신속히 탐색할 수 있는 검색 가능성(Searchability), 원거리에서도 통신망을 통해 자유롭게 이용할 수 있는 원격 조작성(Remote Operability)을 지닌다.
* **보기:**
  1. 정보의 축적 및 전달 측면
  2. 정보 관리 측면
  3. 정보 분석 측면
  4. 기술 발전 측면
* **정답:** **①**
* **해설:** 기계가독성, 검색가능성, 원격조작성은 데이터베이스의 구축 및 활용에 따른 **정보의 축적 및 전달 측면**의 고유한 특성입니다.

### 4번
* **문제:** 빅데이터 수집 및 전처리 단계에서 개인정보 노출 위험을 방지하기 위해 주민등록번호나 성명 등을 가공하여 특정 개인을 알아볼 수 없도록 조치하는 비식별화 기술은?
* **보기:**
  1. 정규화 (Normalization)
  2. 익명화 (Anonymization)

### 5번
* **문제:** 전통적으로 정의된 빅데이터의 3대 핵심 특징(3V)에 해당하지 않는 것은?
* **보기:**
  1. 크기 (Volume)
  2. 다양성 (Variety)
  3. 속도 (Velocity)
  4. 가용성 (Availability)
* **정답:** **④**
* **해설:** 가트너(Gartner)가 제시한 빅데이터의 기본 3요소는 데이터의 양을 의미하는 **Volume(규모)**, 데이터 생성 및 처리 주기를 의미하는 **Velocity(속도)**, 정형·반정형·비정형 데이터를 아우르는 **Variety(다양성)**입니다. '가용성'은 시스템 신뢰성 지표에 해당합니다.

### 6번
* **문제:** 데이터 분석 기법 중 연관분석(Association Analysis)에 대한 설명으로 가장 부적절한 것은?
* **보기:**
  1. 장바구니 분석(Market Basket Analysis)이라고도 불린다.
  2. 대규모 거래 데이터에서 품목 간의 상호 연관 규칙을 발견하는 비지도 학습이다.
  3. 두 연속형 변수 간의 선형적 인과관계를 검정하고 계수를 추정한다.
  4. 규칙의 유의성을 평가하기 위해 지지도, 신뢰도, 향상도 지표를 활용한다.
* **정답:** **③**
* **해설:** 두 연속형 변수 간의 선형 인과관계를 모델링하는 것은 회귀분석(Regression Analysis)의 역할입니다. 연관분석은 사건이나 품목 간의 동시 발생 패턴(조건부 확률)을 규명하는 비지도 학습 기법입니다.

### 7번
* **문제:** 데이터 유형과 특성에 대한 설명 중 잘못된 것은?
* **보기:**
  1. 데이터의 형태(구조)에 따라 적용할 수 있는 수집, 정제 및 분석 방법론이 달라진다.
  2. 데이터는 구조적 형식에 따라 정형(Structured), 반정형(Semi-structured), 비정형(Unstructured)으로 분류된다.
  3. 동영상, 음성 파일, 소셜 미디어 게시글, 이미지 등은 비정형 데이터의 대표적인 예이다.
  4. 사물인터넷 센서 로그, 웹 서버 로그는 정해진 스키마를 엄격히 따르는 전형적인 정형 데이터이다.
* **정답:** **④**
* **해설:** 센서 데이터나 시스템/웹 서버 로그, JSON, XML, HTML 등은 고정된 관계형 테이블 형태(스키마)는 없으나 데이터 내부에 메타데이터나 키-값 구조를 포함하고 있는 **반정형 데이터(Semi-structured Data)**에 해당합니다.

### 8번
* **문제:** 빅데이터 활용 환경의 위기 요인과 그에 대응하는 해결 방안(통제 기제)의 연결이 올바르지 않은 것을 고른 것은?
* **보기:**
  * 가. 사생활 침해 — 데이터 사용자의 책임 원칙 강화
  * 나. 책임 원칙 훼손 — 민주적 절차 및 알고리즘에 대한 접근성 보장(알고리즈미스트)
  * 다. 데이터 오용 — 데이터 수집 동의제(Opt-in)의 엄격화
  1. 가
  2. 다
  3. 가, 나
  4. 나, 다
* **정답:** **② (다)**
* **해설:** 데이터 오용(데이터를 잘못 해석하거나 왜곡된 인과관계로 활용하는 문제)에 대한 통제 기제는 데이터 수집 동의제가 아니라, 알고리즘 및 예측 모델의 활용에 대한 **사후 책임 및 결과 기반 책임 원칙 강화(알고리즘 공정성/설명책임 보장)**입니다. 동의제는 사생활 침해의 고전적 대책이지만 빅데이터 환경에서는 실효성이 낮아 사용자의 책임을 강화하는 쪽으로 패러다임이 전환되었습니다.

### 9번
* **문제:** 다음 보기에서 설명하고 있는 정보 시스템의 데이터 처리 방식은?
> [보기]  
> 주문, 결제, 입출금 등 비즈니스 트랜잭션이 발생하는 즉시 시스템의 데이터베이스에 실시간으로 기록·갱신되며, 데이터의 일관성과 무결성을 보장하는 것이 핵심 목적이다.

  1. OLAP (Online Analytical Processing)
  2. OLTP (Online Transaction Processing)
  3. Data Warehouse
  4. Data Lake

### 10번
* **문제:** 비즈니스 문제 해결을 이끄는 데이터 사이언티스트의 핵심 역량 및 역할에 대한 설명으로 가장 부적절한 것은?
* **보기:**
  1. 분석 결과를 실제 업무 프로세스에 적용하기 위해 도메인 전문 지식(Business Domain Knowledge)이 필수적이다.
  2. 데이터 사이언티스트는 독립적인 분석만 수행하므로 소통 및 설득 능력보다는 고급 모델링 기술이 절대적으로 우선시된다.
  3. 분석 결과를 의사결정권자에게 효과적으로 전달하기 위한 데이터 시각화와 스토리텔링 역량이 요구된다.
  4. 하드 스킬(수학, 통계학, 알고리즘)과 소프트 스킬(통찰력, 협업 역량)의 균형 잡힌 결합이 요구된다.
* **정답:** **②**
* **해설:** 데이터 사이언티스트는 현업 부서 및 경영진과의 긴밀한 협업과 소통을 통해 문제를 정의하고 비즈니스 통찰을 설득해야 하므로, 기술적 모델링 역량뿐만 아니라 **소프트 스킬(소통, 공감, 설득, 협업 능력)**이 대단히 중요합니다.

## 제2과목: 데이터 분석 기획 (11번 ~ 20번)

### 11번
* **문제:** 데이터 분석 기획 시 고려해야 할 위험 관리 요소 중, 분석 모델링 시 주의해야 할 원칙으로 가장 적절하지 않은 것은?
* **보기:**
  1. 모델의 복잡도를 무조건 높일수록 실무 적용성과 설명 가능성이 극대화된다.
  2. 분석 모형의 성능과 함께 현업 적용 가능성 및 비용 효율성을 종합적으로 고려해야 한다.
  3. 유사 프로젝트 사례 및 관련 오픈소스를 검토하여 프로젝트 일정 지연 리스크를 최소화한다.
  4. 데이터 확보의 가능성 및 데이터의 품질 상태를 기획 초기 단계에서 검증해야 한다.
* **정답:** **①**
* **해설:** 지나치게 복잡한 모델은 과적합(Overfitting) 위험이 크고, 연산 자원 소모가 심하며, 현업 의사결정권자에게 결과를 설명하기 어렵습니다. 단순하고 직관적이면서도 해석력이 높은 모형이 실무에서 선호되는 경우가 많습니다(오컴의 면도날 법칙).

---

### 12번
* **문제:** 빅데이터 분석 기법과 해당 기법이 적용된 비즈니스 활용 사례의 연결이 가장 부적절한 것은?
* **보기:**
  1. 연관분석 — 자동차의 효율적인 연비 개선을 위해 엔진 회전수와 변속 비율 간의 최적 상관관계를 도출한다.
  2. 감성분석 — 고객센터 게시판에 등록된 새로운 환불 정책에 대한 고객들의 반응 텍스트를 긍정/부정으로 분류한다.
  3. 사회연결망 분석(SNA) — 조직 내부의 소통 네트워크와 인적 교류 관계망을 시각화하여 핵심 영향력자를 탐색한다.
  4. 분류분석 — 신용카드 고객의 기존 결제 이력을 바탕으로 신규 신청 고객이 부도 위험군인지 정상군인지 예측한다.
* **정답:** **①**
* **해설:** 자동차 부품 특성에 따른 연비 예측 및 최적 제어 관계 분석은 **회귀분석(Regression)**이나 최적화 기법을 적용해야 합니다. 연관분석은 동시 발생 품목 간의 구매 규칙(장바구니 분석 등)을 찾는 기법입니다.

### 13번
* **문제:** 분석 과제 발굴 방식 중 '하향식(Top-Down) 접근법'과 '상향식(Bottom-Up) 접근법'에 대한 설명으로 옳은 것은?
* **보기:**
  1. 하향식 접근법은 사전에 정의된 문제 없이 데이터를 탐색하면서 분석 주제를 발견해 나가는 방식이다.
  2. 상향식 접근법은 비즈니스 문제를 우선 정의하고 이를 해결하기 위해 단계별로 데이터를 분석하는 방식이다.
  3. 실제 분석 환경에서는 하향식 접근법과 상향식 접근법이 상호 보완적으로 결합되어 반복 수행되는 것이 이상적이다.
  4. 상향식 접근법은 전통적인 가설 검정 방식에만 의존하며 탐색적 데이터 분석(EDA)을 지양한다.
* **정답:** **③**
* **해설:** 하향식 접근법은 문제를 먼저 정의하고 해결책을 찾아가는 방식이며, 상향식 접근법은 데이터로부터 출발하여 새로운 패턴과 인사이트를 발굴하는 방식입니다. 현대의 효과적인 분석 기획은 두 접근법을 유기적으로 융합·순환하여 수행합니다.

  * 대상 모름 + 방법 모름: 발견 (Discovery)

* **보기:**
  1. 하한선: -4, 상한선: 20
  2. 하한선: -8, 상한선: 24

  4. 하한선: -6, 상한선: 22
* **정답:** **②**

  * 상한선 $= Q_3 + 1.5 \times \text{IQR} = 12 + (1.5 \times 8) = 12 + 12 = 24$

### 50번
* **문제:** 전체 거래 건수가 100건인 편의점 영수증 데이터에서 품목 $A$와 품목 $B$가 동시에 구매된 거래 건수가 30건일 때, 연관규칙 $A \rightarrow B$의 지지도(Support) 값은?
* **보기:**
  1. 0.15
  2. 0.30
  3. 0.50
  4. 0.60
* **정답:** **②**
* **해설:** 
  * 지지도($\text{Support}$)는 전체 거래 건수 중 품목 $A$와 $B$가 동시에 포함된 거래 건수의 비율입니다.  
  $$\text{Support}(A \rightarrow B) = \frac{n(A \cap B)}{N} = \frac{30}{100} = 0.30$$
