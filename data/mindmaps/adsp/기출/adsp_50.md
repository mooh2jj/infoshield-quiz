## 제1과목: 데이터 이해 (1번 ~ 10번)

### 1번
* **문제:** 다음 중 데이터에서 지혜(Wisdom)에 이르는 가치 창출 과정을 계층적으로 구조화한 DIKW 피라미드의 기본 4단계 구성요소에 해당하지 않는 것은?
* **보기:**
  1. 데이터 (Data)
  2. 정보 (Information)
  3. 통찰 (Insight)
  4. 지혜 (Wisdom)
* **정답:** **③**
* **해설:** DIKW 피라미드는 **데이터(Data) → 정보(Information) → 지식(Knowledge) → 지혜(Wisdom)**의 4단계 계층 구조로 이루어져 있습니다.
  * 데이터(Data): 가공되지 않은 순수한 객관적 사실(Fact)이나 관측값
  * 정보(Information): 데이터에 의미와 맥락(Context)을 부여하여 가공한 결과물
  * 지식(Knowledge): 다양한 정보를 구조화·체계화하여 도출한 유용한 규칙이나 원리
  * 지혜(Wisdom): 축적된 지식에 창의적 통찰과 경험이 결합되어 미래를 예측하고 올바른 판단을 내리는 능력
  * **통찰(Insight)**은 데이터 분석을 통해 도출되는 가치 있는 산출물이나, DIKW 피라미드의 고유한 기본 4단계 명칭에는 포함되지 않는 대표적인 오답 함정 보기입니다.

### 2번
* **문제:** 컴퓨터 및 디지털 정보 시스템에서 데이터를 표현하고 저장하는 단위와 체계에 관한 설명으로 가장 적절한 것은?
* **보기:**
  1. 정보 표현의 물리적·논리적 최소 단위는 1바이트(Byte)이며, 1바이트는 4개의 비트(Bit)로 구성된다.
  2. 1비트(Bit)는 0 또는 1이라는 두 가지 이진 상태 중 하나를 표현하는 최소 정보 단위이다.
  3. 1킬로바이트(KB)는 2진 컴퓨터 시스템에서 정확히 1,000바이트(Byte)를 의미한다.
  4. 레코드(Record)는 데이터를 구성하는 가장 하위의 물리적 최소 단위로 메모리에 직접 매핑된다.
* **정답:** **②**
* **해설:** 
  * ② 컴퓨터 및 디지털 시스템에서 정보를 표현하는 물리적·논리적 최소 단위는 **비트(Bit, Binary Digit)**이며, 0 또는 1의 두 가지 상태를 나타냅니다.
  * ① 1바이트(Byte)는 8개의 비트($1\text{ Byte} = 8\text{ Bits}$)로 구성되며, 영문자 1자나 256($2^8$)가지 상태를 표현할 수 있는 기본 단위입니다. (오답)
  * ③ 디지털 시스템(이진법)에서 1KB는 전통적으로 $2^{10} = 1,024\text{ Byte}$를 의미합니다. (오답)
  * ④ 레코드(Record)는 여러 필드(Field)가 모여 하나의 논리적 데이터 개체를 구성하는 논리적 단위이며, 물리적 최소 단위는 비트입니다. (오답)

### 3번
* **문제:** 다음 중 현대 엔터프라이즈 정보 시스템의 핵심 기반인 데이터베이스(Database)의 일반적인 4대 고유 특성에 대한 설명으로 가장 거리가 먼 것은?
* **보기:**
  1. 통합된 데이터(Integrated Data): 동일한 내용의 데이터가 불필요하게 중복 저장되는 것을 통제하여 데이터의 일관성을 유지한다.
  2. 저장된 데이터(Stored Data): 컴퓨터가 접근하여 처리할 수 있도록 자기 디스크나 SSD 등 컴퓨터 저장 매체에 저장된다.
  3. 운영 데이터(Operational Data): 단순한 임시 산출물이 아니라 조직의 본래 업무 목적과 고유 기능을 수행하기 위해 반드시 유지되어야 할 핵심 데이터이다.
  4. 독립된 단독 데이터(Isolated Data): 보안과 데이터 무결성 보장을 위해 다수의 사용자가 동시에 동일한 데이터에 접근하거나 공유하는 것을 기술적으로 원천 차단한다.
* **정답:** **④**
* **해설:** 데이터베이스의 4대 고유 특성은 다음과 같습니다.
  * **통합된 데이터(Integrated Data):** 데이터의 불필요한 중복을 배제(최소화)하여 일관성을 유지함
  * **저장된 데이터(Stored Data):** 컴퓨터가 판독 가능한 전자적 저장 매체에 저장됨
  * **운영 데이터(Operational Data):** 조직의 고유 업무를 수행하기 위해 지속적으로 관리되는 필수 데이터임
  * **공용 데이터(Shared Data):** 여러 사용자와 서로 다른 응용 시스템들이 동시에 동일한 데이터를 공유하여 활용할 수 있음
  * ④ 데이터베이스는 여러 사용자가 동시에 자원을 공유할 수 있도록 다중 접근(Concurrency)을 지원하는 **공용 데이터(Shared Data)**의 특성을 가집니다. 단독 사용만 허용한다는 설명은 잘못되었습니다.

### 4번
* **문제:** 노나카 이쿠지로의 지식창조 메커니즘(SECI 모델)에서 개인의 오랜 경험, 학습, 시행착오를 통해 체화되어 있으나, 외부로 명확히 언어화하거나 문서 형태로 전달하기 어려운 지식의 유형은?
* **보기:**
  1. 형식지 (Explicit Knowledge)
  2. 암묵지 (Tacit Knowledge)
  3. 메타데이터 (Metadata)
  4. 정형 정보 (Structured Information)
* **정답:** **②**
* **해설:** 
  * **암묵지(Tacit Knowledge):** 개인의 내면에 체화되어 있는 주관적 경험, 노하우, 직관, 신념 등으로 언어나 기호로 쉽게 표현하기 어려운 지식입니다. (사례: 숙련된 장인의 손기술, 노련한 의사의 진단 감각)
  * **형식지(Explicit Knowledge):** 문서, 매뉴얼, 서적, 수식, 데이터베이스 등을 통해 외부에 객관적으로 명확히 표현되고 공유 가능한 지식입니다.
  * SECI 모델은 암묵지와 형식지가 상호작용하면서 공통화(S) → 표출화(E) → 연결화(C) → 내면화(I)를 거쳐 조직의 지식으로 나선형 증폭되는 과정을 설명합니다.

### 5번
* **문제:** 전사적 데이터웨어하우스(DW)에 축적된 방대한 기업 데이터로부터, 마케팅팀이나 영업팀 등 특정 부서나 특정 분석 주제 영역에 맞춰 요약·가공하여 비교적 소규모로 구축한 맞춤형 데이터 저장소는?
* **보기:**
  1. 데이터 마트 (Data Mart)
  2. 데이터 레이크 (Data Lake)
  3. 운영 데이터 저장소 (ODS)
  4. 온라인 트랜잭션 처리 (OLTP)
* **정답:** **①**
* **해설:** 
  * **데이터 마트(Data Mart):** 전사적 데이터웨어하우스(DW)의 전체 데이터 중 특정 부서, 특정 업무 기능, 또는 특정 분석 목적에 특화하여 데이터를 추출하고 가공한 하위 개념의 요약형 데이터베이스입니다.
  * 데이터 레이크(Data Lake): 정형 데이터뿐만 아니라 로그, 이미지, 비디오 등 대규모 비정형·반정형 데이터를 원시 형태(Raw Data) 그대로 보관하는 저장소입니다.
  * ODS(Operational Data Store): 트랜잭션 데이터를 DW로 이관하기 전 정제 및 통합을 수행하는 임시 운영 저장소입니다.

### 6번
* **문제:** 기업이 고객과 관련된 모든 내·외부 접점 데이터를 통합·분석하여, 고객 생애 주기 전반에 걸친 고객 경험을 개선하고 장기적인 충성 고객을 확보하기 위해 구축하는 대표적인 기업 정보 시스템은?
* **보기:**
  1. 공급망 관리 (SCM: Supply Chain Management)
  2. 고객 관계 관리 (CRM: Customer Relationship Management)
  3. 전사적 자원 관리 (ERP: Enterprise Resource Planning)
  4. 제품 수명 주기 관리 (PLM: Product Lifecycle Management)
* **정답:** **②**
* **해설:** 
  * **고객 관계 관리(CRM):** 고객 정보와 접점 활동을 통합 관리하여 고객 유치, 관계 유지, 이탈 방지 및 고객 생애 가치(LTV)를 극대화하는 고객 중심 정보 시스템입니다.
  * SCM: 원자재 공급부터 최종 소비자까지의 유통·물류 프로세스를 최적화하는 공급망 관리 시스템입니다.
  * ERP: 생산, 인사, 재무, 회계 등 기업의 전사적 핵심 업무 자원을 하나의 통합 DB로 관리하는 시스템입니다.

### 7번
* **문제:** 대용량 비정형 데이터를 분산 환경에서 효율적으로 처리하기 위한 하둡(Hadoop) 생태계의 핵심 분산 병렬 프로그래밍 모델인 맵리듀스(MapReduce)에 대한 설명으로 옳은 것은?
* **보기:**
  1. 단일 고성능 메인프레임 서버(Scale-up) 환경에서만 작동하는 실시간 트랜잭션 전용 프레임워크이다.
  2. 입력 데이터를 분할하여 키-값(Key-Value) 쌍으로 변환하는 Map 단계와, 동일 키를 갖는 데이터를 취합·집계하는 Reduce 단계로 나누어 분산 처리한다.
  3. ACID 트랜잭션을 엄격하게 보장하는 분산 관계형 데이터베이스 관리 시스템(RDBMS) 기술이다.
  4. 데이터 저장 시 결측치와 이상치를 사전에 자동으로 완전히 제거해 주는 데이터 정제 도구이다.
* **정답:** **②**
* **해설:** 
  * **맵리듀스(MapReduce)**는 대용량 데이터를 여러 일반 x86 노드로 구성된 분산 클러스터(Scale-out) 환경에서 처리하는 프레임워크입니다.
  * **Map 단계:** 대규모 입력 데이터를 블록 단위로 분할하여 필터링 및 변환을 거쳐 (Key, Value) 쌍으로 생성합니다.
  * **Reduce 단계:** 동일한 Key를 가진 값들을 셔플링·정렬한 후 취합하여 합계, 평균 등의 요약 결과를 산출합니다.

### 8번
* **문제:** 빅데이터 시대의 도래에 따라 기존의 데이터 분석 패러다임이 변화하고 있다. 다음 중 패러다임의 변화 방향으로 가장 올바른 것은?
* **보기:**
  1. 데이터의 사전 정제와 사전 처리를 완료한 후 적재하는 방식에서, 일단 원시 데이터를 대량 수집한 후 사후에 분석 목적에 맞게 처리하는 방식으로 전환되었다.
  2. 모든 분석에서 복잡한 수리적 모델링을 통한 엄격한 인과관계 규명만이 유일한 가치이며, 상관관계 분석은 점차 배제되고 있다.
  3. 데이터의 수집 비용 절감을 위해 전수조사보다는 표본조사의 비중이 비약적으로 증가하였다.
  4. 분석의 신뢰성을 극대화하기 위해 비정형 데이터는 수집을 전면 차단하고 규격화된 정형 데이터만을 분석 대상으로 삼는다.
* **정답:** **①**
* **해설:** 빅데이터 시대의 분석 패러다임 변화:
  1. **사전처리 → 사후처리:** 정형화된 스키마에 맞춰 사전에 정제하던 방식에서, Data Lake 등에 원시 데이터를 그대로 적재한 뒤 필요 시점에 가공하는 방식으로 전환 (Schema-on-Read).
  2. **표본조사 → 전수조사:** 컴퓨팅 자원의 발달로 표본 추출 없이 전체 데이터를 분석할 수 있는 범위가 확대됨.
  3. **질(Quality) → 양(Quantity):** 약간의 잡음(Noise)이 있더라도 방대한 데이터의 양을 통해 전체적 패턴을 포착함.
  4. **인과관계(Why) → 상관관계(What):** 모든 현상의 이론적 원인을 규명하기 전에 데이터 내의 상관관계와 패턴을 발견하여 예측과 의사결정에 신속하게 활용함.

### 9번
* **문제:** 개체(Node) 간의 상호작용과 연결망 구조를 파악하는 소셜 네트워크 분석(SNA: Social Network Analysis)에 대한 설명으로 가장 부적절한 것은?
* **보기:**
  1. 사람, 집단, 조직, 웹페이지 등을 노드(Node 또는 Vertex)로, 이들 간의 연결 관계나 상호작용을 링크(Link 또는 Edge)로 모델링한다.
  2. 네트워크 내에서 특정 개체가 다른 개체들과 얼마나 많은 연결을 맺고 있는지를 측정하는 지표를 '연결 중심성(Degree Centrality)'이라 한다.
  3. 한 노드가 다른 노드들 간의 최단 경로 상에 위치하여 정보의 흐름을 통제하고 중개하는 역할을 측정하는 지표를 '매개 중심성(Betweenness Centrality)'이라 한다.
  4. 소셜 네트워크 분석은 개체 간의 질적 관계만을 파악하므로 행렬(Matrix)이나 그래프 이론을 적용한 수리적 정량화는 불가능하다.
* **정답:** **④**
* **해설:** 소셜 네트워크 분석(SNA)은 그래프 이론(Graph Theory)과 인접 행렬(Adjacency Matrix)을 기반으로 네트워크 밀도, 중심성(연결 중심성, 매개 중심성, 근접 중심성, 고유벡터 중심성) 등을 엄밀하게 수학적·정량적으로 계산하여 분석하는 기법입니다. 정량화가 불가능하다는 설명은 틀렸습니다.

### 10번
* **문제:** 비즈니스 가치를 창출하는 데이터 사이언티스트에게 요구되는 역량 중 통계학, 수학, 알고리즘 구현 및 데이터베이스 튜닝과 같은 '하드 스킬(Hard Skill)'과 구분되는 '소프트 스킬(Soft Skill)'에 해당하는 것은?
* **보기:**
  1. 분산 컴퓨팅 환경에서의 MapReduce 및 Spark 파이프라인 개발 능력

  4. **데이터 마이닝 (Data Mining):** 실제 알고리즘(분류, 군집, 연관규칙 등)을 적용하여 숨겨진 패턴 탐색

  * **확산형 (준비도 높음 & 성숙도 높음):** 전사적 차원에서 분석이 고도화되어 기업 경쟁력의 핵심 동력으로 자리 잡은 상태

### 23번

* **보기:**
  1. $\frac{2}{3}$
  2. $1$
  3. $\frac{4}{3}$
  4. $\frac{3}{2}$
* **정답:** **③**
* **해설:** 향상도(Lift)는 품목 $A$의 구매와 품목 $B$의 구매가 상호 독립일 때에 비해 $A$를 구매했을 때 $B$를 구매할 확률이 몇 배 증가하는지를 나타냅니다.
$$\text{Lift}(A \rightarrow B) = \frac{P(A \cap B)}{P(A) \times P(B)} = \frac{\frac{1}{2}}{\frac{3}{4} \times \frac{1}{2}} = \frac{\frac{1}{2}}{\frac{3}{8}} = \frac{1}{2} \times \frac{8}{3} = \frac{4}{3} \approx 1.333$$
(Lift가 1보다 크므로 두 품목은 양의 상관관계/보완 관계를 가집니다.)

### 47번
* **문제:** 시계열 분석에서 정상 시계열의 차수를 식별할 때, 2차 자기회귀모형인 $\text{AR}(2)$ 모형에서 자기상관함수(ACF)와 편자기상관함수(PACF) 도표가 나타내는 전형적인 패턴은?
* **보기:**
  1. ACF는 시차 2 이후에서 급격히 0으로 절단(Cut-off)되고, PACF는 점진적으로 감소한다.
  2. ACF는 지수적 또는 사인파 형태로 점진적으로 감소(Tails off)하고, PACF는 시차 2($p=2$) 이후에서 급격히 0으로 절단(Cut-off)된다.
  3. ACF와 PACF가 모든 시차에서 동일하게 0을 기록한다.
  4. ACF와 PACF가 모든 시차에서 1로 고정된다.
* **정답:** **②**
* **해설:** 정상 시계열 모형 식별 공식:
  * **$\text{AR}(p)$ 모형:** ACF는 점진적 감쇄(지수적 감쇄 또는 사인파 감쇄: Tails off), **PACF는 시차 $p$ 이후 급격히 절단(Cut-off)**됩니다. 따라서 $\text{AR}(2)$ 모형은 **PACF가 시차 2 이후 절단**됩니다.
  * **$\text{MA}(q)$ 모형:** **ACF가 시차 $q$ 이후 절단(Cut-off)**되고, PACF는 점진적으로 감쇄(Tails off)합니다.
  * **$\text{ARMA}(p, q)$ 모형:** ACF와 PACF 모두 특정 시차 이후 점진적으로 감쇄합니다.
