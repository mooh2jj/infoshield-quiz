# ADsP 제48회 기출문제 및 해설 풀이 (전체 50문항)

---

## 제1과목: 데이터 이해 (1번 ~ 10번)

### 1번
* **문제:** 다음 중 SECI 모델 지식 변환 과정에 관한 설명으로 잘못된 것은?
* **보기:**
  1. 표출화는 암묵지를 전달 가능한 형식지로 변환하는 과정이다.
  2. 연결화는 형식지를 암묵지에 맞게 편집하거나 변환하는 과정이다.
  3. 내면화는 학습이나 행동을 통해 형식지를 개인의 암묵지로 체화하는 과정이다.
  4. 공통화는 개인의 경험이나 지식이 공유되어 다른 사람의 암묵지로 전이되는 과정이다.
* **정답:** **②**
* **해설:** 연결화(Combination)는 형식지들을 조합·편집·분류하여 새로운 형식지를 창출하거나 체계화하는 과정입니다. 형식지를 암묵지로 체화하는 것은 내면화(Internalization)입니다.

### 2번
* **문제:** 아래 보기는 데이터에 대한 일반적인 설명이다. 다음 중 옳은 것을 모두 고른 것은?
* **보기:**
  * 가. 정량적 데이터는 수치 형태로 표현되며, 비정형성을 지닌 정성적 데이터에 비해 많은 분석 비용을 필요로 한다.
  * 나. 정성적 데이터는 문자, 언어, 기호 등으로 구성되며, 개별 데이터 간의 형식적 일관성이나 체계적 구조가 확립되어 있지 않다.
  * 다. 정성적 데이터는 수치 형태로 표현된 객체로서 정량적 데이터에 비해 저장 및 분석이 용이하다.
  * 라. 데이터는 있는 그대로의 사실을 객관적으로 나타내는 존재적 특성을 갖는다.
  * 마. 데이터는 존재적 특성을 넘어 추론을 통한 미래 예측의 기초 자료로 활용될 수 있는 당위적 특성을 갖는다.
  1. 가, 나, 다
  2. 가, 라, 마
  3. 나, 라, 마
  4. 다, 라, 마
* **정답:** **③ (나, 라, 마)**
* **해설:** 
  * 가: 비정형성을 지닌 정성적 데이터(텍스트, 음성, 영상 등)가 정량적 데이터에 비해 저장 및 분석 비용이 훨씬 많이 소요됩니다. (오답)
  * 다: 수치 형태로 표현되어 저장 및 분석이 용이한 것은 정량적 데이터입니다. (오답)
  * 나, 라, 마는 정성적 데이터의 특성 및 데이터의 존재적·당위적 특성을 바르게 설명하고 있습니다.

### 3번
* **문제:** 다음 중 데이터베이스와 DBMS에 대한 설명으로 잘못된 것은?
* **보기:**
  1. 데이터베이스는 체계적으로 관리되는 데이터의 집합이다.
  2. DBMS는 사용자가 데이터베이스를 구축하고 관리할 수 있는 소프트웨어이다.
  3. 데이터베이스와 DBMS를 통칭하여 데이터베이스 시스템이라고 부른다.
  4. 데이터베이스는 문자, 기호, 영상 등 인식 가능한 모든 자료를 의미하는 개념이다.
* **정답:** **④**
* **해설:** 문자, 기호, 영상 등 인식 가능한 모든 원천적인 자료를 의미하는 포괄적인 개념은 데이터베이스가 아닌 '데이터(Data)' 자체입니다. 데이터베이스는 특정 목적을 위해 구조화되어 통합 관리되는 데이터의 집합입니다.

---

### 4번
* **문제:** 다음 중 현대 정보 시스템의 근간을 이루는 데이터베이스의 목적 및 특징에 대한 설명으로 잘못된 것은?
* **보기:**
  1. 데이터베이스는 조직의 업무 목적을 수행하기 위해 상호 연관된 자료들을 구조화하고 통합한 체계적인 데이터의 집합이다.
  2. 데이터의 일관성과 저장 공간의 효율성을 높이기 위해 동일한 정보가 불필요하게 중복되지 않도록 관리한다.
  3. DBMS의 구조적 특성상 다수의 독립적인 사용자가 서로 다른 목적을 위해 자원을 동시에 공유하는 기능은 구현할 수 없다.
  4. 데이터베이스는 변화하는 데이터의 상태를 항상 최신 상태로 유지(동적 변화)한다.
* **정답:** **③**
* **해설:** 데이터베이스의 핵심 특성 중 하나는 여러 사용자가 서로 다른 목적으로 동시에 동일한 데이터에 접근하여 활용할 수 있는 '공용 데이터(Shared Data)' 특성입니다. DBMS는 동시성 제어를 통해 무결성을 유지하며 다중 사용자 접근을 지원합니다.

### 5번
* **문제:** 다음 중 학생의 공부 시간에 따른 성적 변화를 분석할 때 가장 적절한 분석 방법은?
* **보기:**
  1. 회귀분석
  2. 연관분석
  3. 유전자 알고리즘
  4. 소셜 네트워크 분석
* **정답:** **①**
* **해설:** 공부 시간이라는 독립변수(원인)의 변화에 따라 시험 성적이라는 종속변수(결과)가 어떻게 변화하는지 인과관계를 통계적으로 모델링하는 기법은 회귀분석(Regression Analysis)입니다.

  * 나. 사생활 침해
  * 다. 책임 원칙 훼손
  * 라. 알고리즘 개인 공개
  * 마. 데이터 오용
  1. 가, 나, 다
  2. 나, 다, 라
  3. 나, 다, 마
  4. 다, 라, 마

* **해설:** 빅데이터 환경의 3대 위기 요인은 **사생활 침해(Privacy)**, **책임 원칙 훼손(Responsibility)**, **데이터 오용(Misuse/Abuse)**입니다. 익명화와 알고리즘 공개는 이러한 위기 요인을 통제하기 위한 대응 방안(통제 기제)에 해당합니다.

* **보기:**
  1. 데이터
  2. 프로세스
  3. 인력
  4. 기술

* **해설:** 빅데이터 가치 창출의 3대 핵심 요소는 자원으로서의 **데이터(Data)**, 분석을 수행하는 전문 **인력(People)**, 데이터를 저장·처리·분석하는 **기술(Technology)**입니다.

### 8번
* **문제:** 다음 중 비즈니스 환경에서 가치를 창출하는 데이터 사이언티스트의 직무 범위와 핵심 역량에 대한 설명으로 가장 부적절한 것은?
* **보기:**
  1. 조직 내 부서 간 협업을 통해 원천 데이터가 내포하고 있는 전략적 의미를 파악한다.
  2. 자동화된 의사결정 시스템으로 인해 발생할 수 있는 피해를 예방하고 피해 발생 시 적절한 보상 방안을 마련하는 업무를 전담한다.
  3. 데이터 시각화 기법을 활용하여 분석 결과를 논리적으로 구조화하고 의사결정권자에게 스토리텔링 기반의 통찰을 제공한다.
  4. 방대한 데이터를 탐색하고 분석 모델을 적용하여 조직의 성장을 견인할 비즈니스 인사이트를 도출한다.
* **정답:** **②**
* **해설:** 자동화된 알고리즘과 의사결정 시스템으로 인해 발생할 수 있는 부작용, 차별, 윤리적·법적 문제 및 피해 보상을 전문적으로 다루는 직무는 '알고리즈미스트(Algorithmist)'입니다.

### 9번
* **문제:** 다음 중 데이터 사이언스에 대한 설명으로 적절하지 않은 것은?
* **보기:**
  1. 빅데이터는 산업 전반의 기술 혁신을 가속화하고 기업의 생산성을 증대시키는 전략적 자산이다.
  2. 빅데이터는 활용 목적과 방식에 따라 그 가치가 달라지므로 사전에 가치를 정확히 산정하기 어렵다.
  3. 분석 과정에서 기준을 설정하거나 결과를 해석하는 단계에서는 사람의 주관이 개입할 가능성이 있다.
  4. 데이터 사이언티스트의 소프트 스킬에는 이론적 지식과 분석 기술에 대한 숙련이 포함된다.
* **정답:** **④**
* **해설:** 통계학/수학적 이론 지식과 머신러닝, 프로그래밍 등의 분석 기술 숙련도는 '하드 스킬(Hard Skill)'에 속합니다. 소프트 스킬(Soft Skill)은 통찰력, 설득력 있는 전달/스토리텔링, 다학제 간 협업 및 커뮤니케이션 능력을 뜻합니다.

### 10번
* **문제:** 다음 중 빅데이터의 가치 패러다임 변화 과정으로 올바른 순서는?
* **보기:**
  1. 에이전시 → 연결 → 디지털화
  2. 디지털화 → 연결 → 에이전시
  3. 연결 → 디지털화 → 에이전시
  4. 디지털화 → 에이전시 → 연결
* **정답:** **②**
* **해설:** 빅데이터 가치 패러다임은 아날로그의 정보화 단계인 **디지털화(Digitalization)** → 사물과 인터넷이 융합되는 **연결(Connection)** → 복합 데이터를 바탕으로 지능화된 시스템이 스스로 판단하고 작업을 대행하는 **에이전시(Agency)** 순으로 발전했습니다.

## 제2과목: 데이터 분석 기획 (11번 ~ 20번)

### 11번
* **문제:** 다음 중 분석 방법은 이미 알고 있으나, 분석 대상(What)을 모르는 경우에 해당하는 분석 주제 유형은?
* **보기:**
  1. 최적화(Optimization)
  2. 솔루션(Solution)
  3. 통찰(Insight)
  4. 발견(Discovery)
* **정답:** **③**
* **해설:** 분석 대상(What)과 분석 방법(How)에 따른 4가지 유형:
  * 대상 알고, 방법 앎: 최적화 (Optimization)
  * 대상 알고, 방법 모름: 솔루션 (Solution)
  * 대상 모르고, 방법 앎: **통찰 (Insight)**
  * 대상 모르고, 방법 모름: 발견 (Discovery)

---

### 12번
* **문제:** 다음 중 CRISP-DM 분석 방법론의 '데이터 준비(Data Preparation)' 단계에서 수행하는 업무로 적절하지 않은 것은?
* **보기:**
  1. 데이터 탐색 (EDA)
  2. 데이터 정제 (Cleaning)
  3. 데이터 통합 (Integration)
  4. 데이터 포맷팅 (Formatting)
* **정답:** **①**
* **해설:** 데이터 준비 단계는 분석 모델에 투입할 최종 데이터셋을 생성하는 단계(데이터 정제, 통합, 포맷팅, 파생변수 생성 등)입니다. 데이터 탐색(EDA) 및 데이터 품질 식별은 이전 단계인 '데이터 이해(Data Understanding)' 단계에서 수행됩니다.

### 13번
* **문제:** 다음 중 분석 대상을 사전에 명확히 알지 못할 때 수행하는 상향식(Bottom-Up) 접근법에 가장 적절한 분석 기법은?
* **보기:**
  1. 지도 학습 (Supervised Learning)
  2. 비지도 학습 (Unsupervised Learning)
  3. 애자일 방법론 (Agile)
  4. 강화 학습 (Reinforcement Learning)
* **정답:** **②**
* **해설:** 상향식 접근법은 사전에 정의된 문제나 정답(레이블) 없이 원천 데이터 자체의 내재된 규칙과 패턴을 탐색하는 방식이므로, 비지도 학습(군집분석, 연관규칙 등)이 가장 적합합니다.

### 14번
* **문제:** 다음 중 데이터 분석 프로젝트의 품질 관리에 대한 설명으로 가장 적절한 것은?
* **보기:**
  1. 품질 보증 활동은 프로젝트 종료 이후에 집중적으로 수행한다.
  2. 프로젝트의 조기 종료를 목적으로 품질 관리 결과를 평가 기준으로 활용할 수 있다.
  3. 품질 관리는 품질 검토와 품질 보증 활동으로 구분하여 수행된다.
  4. 품질 관리는 외부 기업과의 협력 프로세스를 필수로 거쳐야 수행된다.
* **정답:** **③**
* **해설:** 품질 관리는 프로젝트 수행 절차가 표준에 맞게 진행되는지 점검하는 **품질 보증(Quality Assurance)**과 산출물이 요구사항을 충족하는지 검증하는 **품질 검토(Quality Control)**로 구분하여 프로젝트 전 과정에 걸쳐 상시 수행됩니다.

### 15번
* **문제:** 다음 중 분석 우선순위 결정에 관한 올바른 설명을 고른 것은?
* **보기:**
  * 가. 데이터 양과 분석 범위를 조정하면 문제의 시급성을 낮출 수 있다.
  * 나. 새로운 기술의 도입 여부는 분석과제의 난이도에 영향을 미칠 수 있다.
  * 다. 분석 비용, 적용 비용 및 분석 수준은 시급성에 영향을 미친다.
  1. 가
  2. 나
  3. 다
  4. 가, 다
* **정답:** **② (나)**
* **해설:** 
  * 가: 데이터 양과 범위를 조정하는 것은 구현 '난이도'를 조정하는 것이지, 비즈니스 '시급성'을 변화시키지 못합니다.
  * 나: 신규 기술 도입 여부는 기술적 난이도를 결정짓는 핵심 요소입니다.
  * 다: 비용, 기술 수준, 데이터 복잡도는 시급성이 아닌 '난이도(기술성)' 평가 요소입니다.

### 16번
* **문제:** 다음 중 분석 성숙도 모델에 대한 설명으로 잘못된 것은?

* **문제:** 고객 데이터셋에서 나이 변수에 10%의 결측치가 있고, 성별 변수에도 10%의 결측치가 존재한다. 두 변수의 결측 발생이 서로 독립일 때, 두 변수 중 적어도 하나 이상의 결측치가 있어 해당 고객 레코드가 제거될 확률은?
* **보기:**
  1. 0.01 (1%)
  2. 0.19 (19%)
  3. 0.20 (20%)
  4. 0.81 (81%)
* **정답:** **②**
* **해설:**
  * 나이 변수가 정상일 확률: $1 - 0.10 = 0.90$
  * 성별 변수가 정상일 확률: $1 - 0.10 = 0.90$
  * 두 변수 모두 정상일 확률 (독립 사건): $0.90 \times 0.90 = 0.81$
  * 적어도 하나의 결측치가 발생하여 레코드가 제거될 확률: $1 - 0.81 = 0.19$ ($19\%$)

### 49번
* **문제:** 전체 거래 건수가 1,000건인 마트 데이터에서 품목 $A$가 포함된 거래가 600건이고, 품목 $A$와 $B$가 동시에 포함된 거래가 300건일 때, 연관규칙 $A \rightarrow B$의 신뢰도(Confidence) 값은?
* **보기:**
  1. 0.3
  2. 0.5
  3. 0.6
  4. 0.75
* **정답:** **②**
* **해설:**
  * 신뢰도 $\text{Confidence}(A \rightarrow B) = \frac{\text{Support}(A \cap B)}{\text{Support}(A)} = \frac{n(A \cap B)}{n(A)}$
  * 따라서 $\frac{300}{600} = 0.5$ ($50\%$)입니다.

### 50번
* **문제:** 연관규칙 분석에서의 향상도(Lift)에 대한 설명으로 옳은 것은?
* **보기:**
  1. 품목 $A$와 $B$가 동시에 포함된 거래 비율을 의미한다.
  2. 품목 $A$와 $B$가 서로 독립일 때 향상도 값은 항상 0이 된다.
  3. 품목 $A$가 구매되었을 때 품목 $B$가 구매될 조건부 확률이다.
  4. 향상도가 1보다 클 경우 두 품목 간에 양의 연관성(상호 보완 관계)이 존재한다고 해석한다.
* **정답:** **④**
* **해설:**
  * ①은 지지도(Support)에 대한 설명입니다.
  * ②: 두 품목이 상호 독립일 때 향상도는 0이 아니라 1입니다 ($\frac{P(A \cap B)}{P(A)P(B)} = 1$).
  * ③은 신뢰도(Confidence)에 대한 설명입니다.
  * ④: 향상도가 1보다 크면 품목 $A$ 구매가 품목 $B$ 구매 가능성을 유의미하게 높여주는 양의 상관(보완 관계)을 의미합니다.
